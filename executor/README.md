# executor

Freqtrade configuration and dry-run (paper trading) setup.

## Contents
- `config.json` — Freqtrade config (dry-run mode, Binance public data)
- `user_data/` — generated by Freqtrade at runtime (gitignored)

## Notes
- Never store API keys here. All secrets go in `../.env` only.
- This directory configures the executor only — strategy logic lives in `/strategies`.
